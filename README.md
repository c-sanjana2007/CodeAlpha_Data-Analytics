# CodeAlpha Data Analytics Internship

## Task 1: Web Scraping


### Project Overview
This project involves collecting book information from a public practice website using Python web scraping technique


### Objective
To extract useful book details from a website and create a structured dataset for analysis.


### Technologies Used
- Python
- Requests
- BeautifulSoup
- Pandas
- Jupyter Notebook


### Data Collected
The dataset contains the following columns:
- **Title:** Name of the book
- **Price:** Price of the book
- **Availability:** Stock availability
- **Rating:** Book rating


### Process
1. Connected to the Books to Scrape website.
2. Extracted book titles, prices, availability, and ratings.
3. Created a structured dataset using Pandas.
4. Checked for missing values.
5. Cleaned price data and performed basic analysis.
6. Exported the dataset to a CSV file.


### Files Included
- `webscraping.ipynb` — Python code and analysis.
- `scraped_books.csv` — Extracted book dataset.


### Results
Successfully collected and analyzed 20 books with 4 columns. No missing values were found in the dataset.
